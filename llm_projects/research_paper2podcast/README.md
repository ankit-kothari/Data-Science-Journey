# Research Paper to Podcast

LLM pipeline that converts academic papers into podcast-style audio — PDF parsing, summarization, conversational script generation, and audio synthesis.

## Objective

Automate the transformation of dense research papers into an accessible conversational format, end-to-end.

## Pipeline

```
PDF → Text Extraction → Section Summarization → Conversational Script → Audio Generation
```
